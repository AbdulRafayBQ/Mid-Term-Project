# PROJECT KE BARE MEIN

Kaam Krwao aik modern service marketplace web application hai jahan customers apni rozmarrah ki zaroorat ke liye suitable Ustaad ya Service Professional dhoond sakte hain.

Customer apna kaam post kar sakta hai, job ki details de sakta hai, location aur urgency select kar sakta hai, photos aur videos upload kar sakta hai aur suitable Ustaad select kar sakta hai.


# MAIN FEATURES

• Job Posting
Customer apni service ki requirement post kar sakta hai.

• Ustaad Profile
Professional apni skills aur experience show kar sakta hai.

• Ustaad Verification
Ustaad ke liye verification ka flow.

• Service Categories
Mukhtalif service categories available hain.

• Ratings Aur Reviews
Customer Ustaad ko rate aur review kar sakta hai.

• Location
Job ki location aur urgency select karne ka option.

• Photos Upload
Job ke mutaliq photos share ki ja sakti hain.

• Videos Upload
Job ki video details bhi share ki ja sakti hain.

• Chat
Customer aur Ustaad ke darmiyan communication interface.

• Dashboard
Customer aur Ustaad ke liye dashboard experience.

• Notifications
Interactive notifications aur toast messages.

• Responsive Design
Mobile, tablet aur desktop friendly interface.

# LOCAL RUN KA TARIKA

1. Project ko download ya clone karein.
2. Project folder ko VS Code mein open karein.
3. index.html file open karein.
4. VS Code mein Live Server use karein.
5. Browser mein website open ho jayegi.

# PROJECT KA MAQSAD

Kaam Krwao ka basic maqsad customers aur skilled service professionals ke darmiyan aik simple aur modern digital connection banana hai.

Customer apni zaroorat ka kaam post karta hai aur relevant Ustaad ko select kar sakta hai. Is se ghar, shop ya office ke kaam ke liye suitable professional dhoondna asaan ho jata hai.


# MAIN SERVICE CATEGORIES

• Plumber
• Electrician
• Carpenter
• Painter
• Tech Expert


# KAAM KAISE KARTA HAI

CUSTOMER

1. Service ki zaroorat batayein.
2. Job details aur location submit karein.
3. Photos ya videos attach karein.
4. Available Ustaads ko dekhein.
5. Suitable Ustaad select karein.
6. Job ka status track karein.


# USTAAD

1. Ustaad ke taur par register karein.
2. Apni skills aur experience add karein.
3. Verification complete karein.
4. Available jobs dekhein.
5. Customer ke saath communicate karein.
6. Job complete karein.
